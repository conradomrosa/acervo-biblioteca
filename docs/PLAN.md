# PLANO

**Data:** 08/10/2026

**Objetivo:** construir um software para gestão do acervo de bibliotecas. Nesse caso, o software será utilizado por uma igreja local da IPB.

**Observação:** este projeto (1) faz parte do desáfio de 30 dias que propus a mim mesmo, onde desenvolverei um software completo por dia durante 30 dias, partindo da arquitetura até a implementação completa de cada um.

## Propósito

O software deve rodar no navegador. O motivo é simples: quero que ele possa ser acessado em qualquer tipo de celular e computador.

Qualquer pessoa poderá acessar o site e verificar quais livros estão disponíveis no acervo da biblioteca. Caso ela deseje pegar algum livro emprestdo, basta ela ir presencialmente até a biblioteca e solicitar ao bibliotecário. O bibliotecário deve poder cadastrar qualquer tipo de livro no acervo do site e também removê-los ou mostrar que foram alugados.

Não será exigido login ou senha dos membros para poder visualizar os livros disponíveis, mas será exigido cadastro para o bibliotecário poder fazer alterações no site.

O site deve permitir que o bibliotecário: crie categorias para cada livro, separando-os em listas; adicione livros; remova livros; etiquete livros que foram alugados; configure título, imagem de banner e cor do site para a sua biblioteca específica. Além disso, o bibliotecário tem acesso ao nome das pessoas que estão com os livros emprestados (o nome de cada uma, a data do empréstimo e de quando devem os livros ser devolvidos).
